# RE4R Lua Executor

A custom Lua executor for **Resident Evil 4 Remake**, built using REFramework.

Created by **Amadeusz RE**.

## Features

- Custom ImGui interface
- Execute custom Lua scripts
- Lua execution status and history
- Automatic ammunition detection
- Snapshot A/B system
- Infinite Ammo toggle
- Lua error handling

## Requirements
-## Compatibility

Designed to work with all REFramework versions.

(The executor should be compatible with different REFramework releases, although compatibility is not officially guaranteed or tested on every version.)

- Resident Evil 4 Remake (PC)
- REFramework

## Installation

1. Download the latest version from GitHub.
2. Extract the downloaded files.
3. Copy the `reframework` folder into your Resident Evil 4 Remake game directory.
4. Launch the game.
5. Open the REFramework menu.

## How to use

Paste the entire script—you can even use Notepad—and save it with the filename `re_executor.lua` 
into the reframework/autorun path within the game's local files.

### Lua Executor

1. Open the RE Lua Executor window.
2. Enter your Lua code.
3. Click **Execute**.
4. Check the execution status.

### Infinite Ammo

1. Click **Snapshot A**.
2. Shoot 1–3 times without reloading.
3. Click **Snapshot B**.
4. Enable **Infinite Ammo**.
